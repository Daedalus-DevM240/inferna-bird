# Infernal Bird 🌋🔥

A high-contrast, volcanic-themed arcade game built with HTML5 Canvas and JavaScript. Navigate the fiery abyss, dodge deadly magma pillars, and survive the heat as the ultimate infernal phoenix.

## 🚀 Features

* **Intrusive Arcade Action:** Fast-paced mechanics inspired by classic flap gameplay, tuned with smooth gravity and responsive jump physics.
* **Volcanic Aesthetic:** Custom CSS and Canvas rendering featuring dark backgrounds, radiant fire elements, and a stylized glowing phoenix.
* **Real-Time Score Tracking:** Dynamic magma scoring system that tracks your survival distance directly on screen.
* **Monetization Ready:** Built-in responsive Google AdSense banner placeholders integrated cleanly into the header layout.

## 🛠️ Built With

* **HTML5 Canvas:** Core game loop, rendering engine, and collision detection.
* **CSS3:** Responsive container styling and high-contrast volcanic visual theme.
* **JavaScript (ES6):** Game state management, physics calculations, and event handling.

🎮 How to Play
Open the game in any modern web browser.

Press the Spacebar or click/tap on the canvas to make the phoenix flap upward.

Avoid colliding with the top/bottom boundaries and the incoming magma pillars.

Press Spacebar or click again to restart instantly after crashing.

🌐 Deployment & Live Demo
This project is optimized for static deployment platforms. To deploy your own instance via GitHub Pages:

Push your repository to GitHub under the main branch.

Navigate to your repository Settings > Pages.

Select the main branch as the source and save.

Access your live game via the generated GitHub Pages URL.
